*Version 1.0 · Updated 26 October 2026*

This document lists the data sources Địa Thế uses for location analysis, each source's licence, and attribution requirements. Địa Thế respects each source's terms. The licence that applies is the one the provider published when Địa Thế downloaded the data; if this summary differs from the original licence, the original licence prevails.

## 1. Principles for using sources

- Use only sources whose licence allows use in a commercial service, or with suitable consent from the provider.
- Credit sources as each licence requires.
- Keep layers under different licences separate so that no unintended share-alike duty arises.
- Keep an internal record for every source: original address, licence, attribution terms, download date and data version.
- A new source is added only after its licence is checked. This document is updated when sources change.

## 2. Source list

**OpenStreetMap**
- Used for: base map, roads, amenities, schools, parks, water, stations, stops.
- Licence: Open Database License (ODbL).
- Attribution: © OpenStreetMap contributors, https://www.openstreetmap.org/copyright. Shown on the map and in results.
- Note: some parts may have to be shared again under ODbL if Địa Thế publishes a derived database.

**WorldPop**
- Used for: estimated population density on a grid.
- Licence: Creative Commons Attribution 4.0 (CC BY 4.0).
- Attribution: WorldPop, with the dataset name and version used.

**GHSL (Global Human Settlement Layer)**
- Used for: cross-checking population against WorldPop.
- Licence: under the European Commission (JRC) terms, attribution required.
- Attribution: European Commission, Joint Research Centre.

**OpenAQ**
- Used for: air quality readings from monitoring stations.
- Licence: under the licence of each data provider that OpenAQ aggregates; attribution is usually required.
- Attribution: OpenAQ and the data provider where available.
- Access is by API key and follows OpenAQ's usage limits.

**FABDEM**
- Used for: ground elevation.
- Licence: the Vietnam edition published by the University of Bristol, under the licence stated on the download page when the data was downloaded. Địa Thế does not use editions whose licence does not allow commercial use.
- Attribution: Hawker et al., University of Bristol; dataset name and version.

**JRC Global River Flood Hazard**
- Used for: modelled river flood depth at return periods.
- Licence: under the European Commission (JRC) terms for Copernicus programme data.
- Attribution: European Commission, Joint Research Centre, Copernicus Emergency Management Service.
- Note: not an official flood hazard map and does not simulate rain-driven flooding.

**ESA WorldCover**
- Used for: land cover and vegetation share.
- Licence: Creative Commons Attribution 4.0 (CC BY 4.0).
- Attribution: © ESA WorldCover project, with the data version.

**GTFS public transport data**
- Used for: bus stops and metro stations.
- Licence: under the terms of the publisher of the dataset used when it was downloaded.
- Attribution: the publisher's name and the data date. This is not real-time operating data from the transit operator.

**Overture Maps (Places), where used**
- Used for: cross-checking amenity density where open map data is sparse.
- Licence: under the licence of each data theme published by Overture.
- Note: kept as a separate layer and not merged into the OpenStreetMap database.

**Third-party geocoding and map services**
- Used for: the address search box and map functions where applicable.
- Terms: the provider's terms of service at the time of use. Địa Thế does not store or redistribute their data beyond what their terms allow.

## 3. What you may and may not do

- You may view and use analysis results for personal, non-commercial purposes.
- You may not bulk-collect, redistribute or resell raw data from Địa Thế. If you need the original data, get it directly from the source under that source's licence.
- Provider data belongs to the provider. Địa Thế may use it only within the licence.

## 4. Updates and mistakes

Each source has its own frequency and delay, described in the Analysis Data Statement. If you think a source is being used contrary to its licence, tell us through the Contact Channel so Địa Thế can check and correct it.
