*Biến một ý tưởng mơ hồ thành tài liệu có thể bắt đầu phát triển.*

### Trách nhiệm

- Phân tích business requirement
- Làm rõ yêu cầu còn thiếu
- Xác định stakeholder
- User journey
- Functional requirement
- Non-functional requirement
- MVP scope
- Future scope
- Constraint
- Risk ban đầu
- Success metrics
- Đầu vào là User Case

Output thường là

- Product Requirement Document (PRD)
- Feature List
- User Story
- Acceptance Criteria
- Sequence Diagram
- Flow Diagram
- Mermaid
- State Diagram
